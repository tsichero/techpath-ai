# 🚀 TechPath AI  
### Seu caminho inteligente para a carreira em tecnologia

---

## 💻 Sobre o Projeto  
O **TechPath AI** é uma aplicação desenvolvida para orientar profissionais na escolha, transição e evolução de carreira na área de tecnologia utilizando Inteligência Artificial.

Inspirado na metodologia prática da **DIO.me**, este projeto foi construído com foco em aplicação real de mercado, unindo tecnologia, estratégia e experiência do usuário.

---

## 🎯 Proposta de Valor  

> Descubra qual carreira em tecnologia realmente faz sentido para você — com ajuda da Inteligência Artificial.

O sistema analisa perfis, interesses e objetivos para recomendar caminhos profissionais mais assertivos dentro do universo tech.

---

## 🧩 Funcionalidades  

- 🔍 Análise de perfil profissional  
- 🧠 Recomendação de carreira com IA  
- 📚 Sugestão de trilhas de aprendizado  
- 🗺️ Roadmap personalizado  
- 📊 Direcionamento estratégico de habilidades  
- 🚀 Planejamento de evolução profissional
